종합안 블록 해설

1주문 완료 성공 배너
기존 그대로. 새 컴포넌트 아님 유지
2입금기한 헤드라인
"7월 25일(금) 오전 5시까지 입금해주세요" — 절대시각, 브랜드 그린 강조. 배송 문구는 삭제하지 않고 이 아래 서브카피로 이동 지예안 절충
3금액 · 계좌 카드
입금하실 금액 대형 그린 → 은행명 → 계좌번호 하이픈 그룹핑 대형 → 예금주 → [계좌번호 복사] 버튼(복사 토스트) A안 구조 양측 일치
4자동취소 · CS 안내
회색 1줄 안내 + 입금자명 / 예금주 / 마이페이지 소형 3줄. 빨강·주황 경고색 미사용 톤 = 지예안 내용 = A안
5알림톡 다시 받기
완료화면 이탈 후 입금 유도 안전망. 발송 주체 확인 필요해 2차로 2차 과제
6결제 요약 · 주문내역
총 결제금액 / 총 할인금액 / 수령일 / 주문내역 자세히보기 — 변경 없음 유지
