PART 01

블록이라는 개념

노션에서 글을 쓸 때 가장 먼저 이해해야 하는 개념입니다. 워드는 한 장의 종이에 글을 쭉 쓰지만, 노션은 레고 블록을 하나씩 쌓아 문서를 만듭니다. 제목도 블록, 문단도 블록, 표도 블록, 이미지도 블록입니다.

블록을 다루는 손잡이

버튼이름하는 일
+블록 추가클릭하면 그 아래에 새 블록이 생기고 종류를 고를 수 있습니다
⠿블록 손잡이끌면 블록 위치를 옮기고, 누르면 블록 메뉴가 열립니다

블록 메뉴 — 지우기 · 복제 · 종류 바꾸기

새 블록 만들기 — 슬래시 /

빈 줄에서 /를 입력하면 넣을 수 있는 블록 목록이 뜹니다. 이어서 이름을 입력해 좁힐 수 있습니다. 예를 들어 /콜아웃, /표, /구분선 처럼 씁니다.

목록을 쓰다가 Enter를 두 번 누르면 목록이 끝나고 일반 문단으로 돌아옵니다. 목록에서 못 빠져나와 당황하는 경우가 가장 흔한 첫 실수입니다.

삭제와 복구

알아두면 좋은 것

노션에는 저장 버튼이 없습니다. 입력하는 즉시 저장됩니다. 그래서 실수도 즉시 반영됩니다. 되돌리려면 Ctrl + Z, 그보다 오래됐다면 버전 기록을 쓰세요.

링크 복사

상단바의 링크 복사하기를 누르면 그 페이지 주소가 복사됩니다. 구글챗이나 메일에 붙여넣어 공유할 수 있습니다. 단, 상대에게 그 페이지 권한이 있어야 열립니다.

뷰 — 같은 데이터를 다른 방식으로 보기

뷰어떤 때 편한가
표모든 값을 한눈에. 가장 기본
보드진행상황별로 카드가 열을 이룸. 업무 현황 파악에 좋음
캘린더날짜(데드라인) 기준으로 볼 때
리스트제목 위주로 단순하게 볼 때
갤러리이미지가 중요한 경우 (제품, 디자인 시안)
타임라인기간이 있는 일정을 막대로 볼 때
가장 흔한 오해

뷰를 바꾼다고 데이터가 바뀌지 않습니다. 보여주는 방식만 달라질 뿐, 원본은 하나입니다. 반대로 표에서 값을 고치면 보드·캘린더에도 즉시 반영됩니다.

단순 표 vs 데이터베이스 구분법

단순 표
  • 줄을 클릭해도 페이지가 안 열림
  • 필터·정렬 버튼이 없음
  • /표 로 만듦
  • 간단한 비교 정리용
데이터베이스
  • 줄을 클릭하면 페이지가 열림
  • 위쪽에 필터 · 정렬 · 새로 만들기 버튼이 있음
  • 뷰 탭(표/보드/캘린더)이 있음
  • 여러 사람이 계속 쌓아가는 업무 기록용

PART 06

협업 기능

노션은 혼자 쓰는 메모장이 아니라 여러 명이 같은 문서를 동시에 보는 도구입니다. 그래서 상대를 부르는 방법과 의견을 남기는 방법이 정해져 있습니다.

@ — 사람 · 페이지 · 날짜 넣기

입력결과
@ + 사람 이름그 사람이 태그되고 수신함에 알림이 갑니다
@ + 페이지 이름다른 문서로 가는 링크가 만들어집니다
@ + 날짜 / @오늘날짜가 삽입됩니다
@는 신중하게

사람을 @로 부르면 상대에게 알림이 갑니다. 단순히 이름을 언급하려는 거라면 그냥 글자로 쓰고, 정말 확인이 필요할 때만 멘션하세요.

"이 문서를 누가 볼 수 있는가"는 노션에서 아주 중요합니다. 내가 개인 페이지에 쓴 글은 아무도 못 보고, 팀스페이스에 쓴 글은 팀 전체가 봅니다.

공유 창

권한 4단계

권한할 수 있는 일
전체 허용내용 편집 + 다른 사람 초대까지 가능
편집 허용내용을 고칠 수 있음
댓글 허용읽고 댓글만 가능. 본문은 못 고침
읽기 허용보기만 가능

어디에 문서를 만들어야 하나

아직 정리 중인 초안인가?
→ 개인 페이지에서 작성
↓
팀이 함께 봐야 하는가?
→ 완성 후 팀스페이스로 옮기기
↓
특정 몇 명만 봐야 하는가?
→ 공유로 개별 초대
팀스페이스에서 바로 쓰면 생기는 일

팀스페이스에 문서를 만들면 그 순간부터 팀원들에게 계속 알림이 갈 수 있습니다. 정리가 덜 된 초안은 개인 페이지에서 쓰고, 다 되면 옮기는 편이 서로 편합니다.

PART 08

찾기

문서가 쌓이면 사이드바를 뒤지는 것보다 검색이 훨씬 빠릅니다. 노션을 잘 쓰는 사람은 사실상 검색으로만 이동합니다.

방법이럴 때
Ctrl + P문서 이름이 대충 기억날 때 (가장 빠름)
사이드바 · 최근 항목조금 전에 보던 문서로 돌아갈 때
즐겨찾기매일 여는 문서. 상단바 별 아이콘으로 등록
데이터베이스 안 검색특정 DB 안에서만 찾을 때
브라우저에서 인쇄 창이 뜨면

간혹 브라우저가 Ctrl + P를 인쇄 단축키로 가로채기도 합니다. 그럴 땐 Ctrl + K를 쓰거나 사이드바의 검색을 누르면 됩니다. 단, 글자를 선택한 상태에서 Ctrl + K를 누르면 검색이 아니라 링크 입력이 됩니다.

즐겨찾기를 먼저 정리하세요

입사 후 첫 주에 자주 쓰는 문서 5~10개를 즐겨찾기에 등록해두면, 이후 문서를 찾아 헤매는 시간이 크게 줄어듭니다.

PART 09

내보내기 · 인쇄

회의에 종이로 들고 가거나 외부에 파일로 전달해야 할 때 씁니다.

형식쓰임
PDF인쇄용, 외부 전달용. 가장 많이 씁니다
HTML웹페이지 형태로 저장
Markdown & CSV다른 도구로 옮길 때. 데이터베이스는 CSV로 나옵니다
인쇄가 잘리지 않게 하려면
  1. 내보내기 형식을 PDF로 지정
  2. 페이지 형식을 A3로 지정해서 내보내기
  3. PDF를 열어 인쇄할 때 용지를 A4, 배율을 페이지에 맞춤으로 설정
  4. 미리보기에서 표가 잘리지 않았는지 확인
출력물 관리

노션에 있는 내용은 회사 자산입니다. 업무 목적 외 사용이나 외부 유출이 없도록 하고, 출력한 문서는 사용 후 폐기해 주세요.

윈도우와 맥의 차이

노션 화면 구성과 기능은 윈도우와 맥이 똑같습니다. 다른 건 모드키(조합키) 이름과 몇 가지 운영체제 기능뿐입니다.

역할윈도우맥

화면 캡처에 대하여

이 문서의 캡처는 브라우저에서 열은 노션 화면입니다. 노션은 윈도우 · 맥 · 브라우저 어디서 열든 화면과 메뉴 이름이 동일해서, 윈도우 PC에서도 보이는 모양이 같습니다. 창 모서리의 창 닫기 버튼 모양 정도만 다릅니다.

PART 11

막혔을 때 Q&A

신규 입사자가 실제로 가장 자주 부딪히는 상황들입니다.

실수로 페이지를 지웠어요

바로 지웠다면 Ctrl + Z로 되돌아옵니다. 시간이 지났다면 사이드바 맨 아래 휴지통에서 찾아 복원하세요. 완전히 사라진 것이 아닙니다.

남의 문서를 실수로 고쳤어요

페이지 메뉴 … → 버전 기록에서 이전 시점을 골라 되돌릴 수 있습니다. 누가 언제 무엇을 바꿨는지도 함께 보입니다. 되돌린 뒤 담당자에게 한마디 남겨두면 더 좋습니다.

표인데 필터 버튼이 없어요

그건 단순 표이고 데이터베이스가 아닙니다. 단순 표는 필터·정렬·뷰 전환이 되지 않습니다. 줄을 클릭했을 때 페이지가 열리는지로 구분하면 가장 확실합니다.

알림이 너무 많이 와요

페이지 메뉴 … → 알림 받기를 꺼서 특정 페이지의 알림을 멈출 수 있습니다. 계정 전체 알림은 설정 → 알림에서 조정합니다. 메일 알림은 꺼두고 노션 안 수신함만 보는 방식을 권합니다.

사이드바에 특정 팀스페이스가 안 보여요

그 팀스페이스에 아직 참여되지 않았거나 권한이 없는 상태입니다. 문서가 사라진 게 아니니 팀장 또는 경영지원HQ에 참여 요청을 하세요.

공유받은 링크를 열었더니 접근 권한이 없다고 나와요

링크는 주소일 뿐, 권한과는 별개입니다. 문서 소유자에게 공유에서 나를 추가해 달라고 요청하세요.

목록에서 빠져나올 수가 없어요

목록 항목에서 Enter를 한 번 더 눌러 빈 항목을 만든 뒤, 다시 Enter를 누르면 일반 문단으로 빠져나옵니다.

저장은 어떻게 하나요

저장 버튼이 없습니다. 입력하는 즉시 자동 저장되고 다른 사람에게도 실시간으로 보입니다. 그래서 완성 전 초안은 개인 페이지에서 쓰는 편이 좋습니다.
